Retail Sales Data Analysis

Project Overview

This project analyzes retail sales data to identify sales trends, profitability, customer behavior, and business performance.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

Key Performance Indicators

- Total Sales: $2,297,200
- Total Profit: $286,397
- Total Orders: 5,009
- Total Customers: 793
- Average Order Value: $458.61
- Overall Profit Margin: 12.46%

Analysis Performed

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Category and Product Analysis
- Customer and Regional Analysis
- Sales Trend Analysis
- Discount and Shipping Analysis
- Correlation Analysis
- Business Insights and Recommendations

Key Findings

- Technology was the highest-selling category.
- West region recorded the highest sales and profit.
- California had the highest state-level sales and profit.
- Texas recorded the highest state-level loss.
- 2017 recorded the highest annual sales.

Project Files

- Dataset: Original retail sales CSV
- Notebook: Python analysis notebook
- Visualizations: Sales dashboard

Conclusion

This project demonstrates the use of Python and data analysis techniques to generate meaningful business insights from retail sales data.
